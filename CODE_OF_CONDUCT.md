# Code de conduite

Ultrawide Monitor est un projet communautaire. Toute participation doit rester
respectueuse, constructive et exempte de discrimination, de harcèlement et de
menaces.

Les mainteneurs peuvent retirer un commentaire, fermer une issue ou refuser une
contribution qui ne respecte pas ces règles. Pour signaler un problème de
conduite, contactez [ImRedTV](https://github.com/ImRedTV) en privé.
