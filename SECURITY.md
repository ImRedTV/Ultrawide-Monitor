# Politique de sécurité

## Signaler une vulnérabilité

Ne publiez pas de vulnérabilité dans une issue publique.

Utilisez de préférence les [avis de sécurité privés GitHub](https://github.com/ImRedTV/Ultrawide-Monitor/security/advisories/new). Si cette fonction n’est pas disponible, contactez [ImRedTV](https://github.com/ImRedTV) en précisant :

- la version concernée ;
- le système et l’architecture ;
- les étapes de reproduction ;
- l’impact observé ;
- une preuve minimale permettant de confirmer le problème.

Un accusé de réception sera envoyé lorsque le signalement aura été examiné. Merci de ne pas divulguer publiquement le problème avant qu’un correctif ou une recommandation soit disponible.

## Périmètre

Ultrawide Monitor fonctionne localement. Il ne collecte pas de télémétrie et ne nécessite pas de compte. Les journaux sont conservés localement dans `%LocalAppData%\UltrawideMonitor\logs`.

Les signalements concernant des fenêtres, l’agent administrateur, les canaux nommés, le stockage de configuration ou l’installateur sont prioritaires.
